# Pi Tasks demo video script (2:45)

Start on a clean demo board. Use demo accounts, sample copy, and no real wallet or credentials. Export the video and upload it publicly to YouTube or another video platform, then place the link in the Pi Next submission.

| Time | On-screen action | Narration |
| --- | --- | --- |
| 0:00–0:25 | Open the board. Show the Pi Tasks wordmark and **Demo mode** badge. | “This is Pi Tasks, a micro-bounty board for Pioneers. Small jobs often get buried in group chats. Here, a community organizer or builder can state exactly what they need and what the work is worth, and a contributor can find a task that fits.” |
| 0:25–0:50 | Filter by Design, search for “palette,” then clear the filters. | “Browse by skill, search the work, or sort by deadline and reward. Every listing shows a clear Pi amount and the last day it can be claimed.” |
| 0:50–1:20 | Sign in as Maya. Post “Proofread the meetup guide,” choose Writing, add a description, set 4 Pi and a future claim deadline. | “Maya posts a small writing bounty: proofread the meetup guide for four Pi. Posting promises a reward but does not reserve or move Pi.” |
| 1:20–1:55 | Switch to Jordan. Claim the task, enter a completion note, and select **Mark complete**. | “Jordan claims the job and shares the finished work in a completion note. The task is now submitted, so Maya can review what Jordan did before releasing the reward.” |
| 1:55–2:20 | Switch to Maya, confirm the submission and click **Release demo reward**. Return to Jordan and open **My profile**. | “The demo records the reward without sending any Pi. Jordan’s profile now lists the completed job and one reputation point.” |
| 2:20–2:45 | Show the demo badge and, if configured, a safe shot of the Pi Sandbox sign-in screen with no account details. Close on the logo. | “Demo mode works without a Pi account. The optional Sandbox uses official Pi sign-in and can verify a Testnet payment from the poster to the app. The payout to the claimer is still simulated. That’s Pi Tasks: small tasks, real impact.” |
